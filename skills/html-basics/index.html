HTML 入门笔记：从零开始理解网页结构

什么是 HTML

HTML（超文本标记语言）可以理解为网页的骨架。就像盖房子需要先搭框架一样，做网页也是用 HTML 来搭建基本结构。

💡 通俗理解：如果把网页比作一个人，HTML 就是骨骼，CSS 就是衣服和化妆，JavaScript 就是肌肉和动作。

最简单的 HTML 页面

下面是一个最简单的 HTML 页面：

<!DOCTYPE html>
<html>
  <head>
    <title>我的第一个网页</title>
  </head>
  <body>
    <h1>欢迎来到我的网站！</h1>
    <p>这是我的第一段文字。</p>
  </body>
</html>

核心概念：标签

HTML 使用”标签”来标记内容。标签通常是成对出现的：

  • 开始标签：<标签名>
  • 结束标签：</标签名>
  • 内容放在两个标签之间

例如：

<p>这是一段文字</p>

<p> 是开始标签，</p> 是结束标签，中间是文字内容。p 代表 paragraph（段落）。

常用标签速查

标题标签

<h1>一级标题（最大）</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>

段落和文本

<p>这是一个段落。</p>
<strong>加粗文字</strong>
<em>斜体文字</em>

链接

<a href="https://example.com">点击跳转到网站</a>

图片

<img src="/images/photo.svg" alt="照片描述" />

列表

<!-- 无序列表 -->
<ul>
  <li>第一项</li>
  <li>第二项</li>
</ul>

<!-- 有序列表 -->
<ol>
  <li>第一步</li>
  <li>第二步</li>
</ol>

块级元素与行内元素

这是一个重要的概念：

  • 块级元素（如 <div>、<p>、<h1>）：独占一行，从上到下排列
  • 行内元素（如 <span>、<a>、<strong>）：在一行内排列，不换行

⚠️ 注意：块级元素里面可以放行内元素，但行内元素里面最好不要放块级元素，否则可能会出现布局问题。

实用的结构标签

HTML5 引入了一些语义化标签，让页面结构更清楚：

<header>   <!-- 页头区域，放导航和 logo -->
<nav>      <!-- 导航菜单 -->
<main>     <!-- 主要内容区域 -->
<article>  <!-- 独立的文章内容 -->
<section>  <!-- 页面中的一个区块 -->
<footer>   <!-- 页脚，放版权等信息 -->

使用这些标签的好处是：代码更容易看懂，搜索引擎也更容易理解你的页面内容。

学习建议

  1. 先理解结构，再关注样式：不要一开始就纠结好不好看，先把内容结构搭对
  2. 多动手写：看十遍不如自己写一遍
  3. 用浏览器开发者工具：按 F12 可以查看任何网页的 HTML 结构
  4. 不要死记硬背：标签用多了自然就记住了，忘记时随时去查就行
