# 个人博客网站

## 项目简介

这是一个面向新手的个人博客网站。使用 Astro 静态框架构建，所有文章以 Markdown 格式管理，不需要数据库和后台系统。

## 核心功能

- 四大核心板块：生活分享、AI 资讯、技能学习、项目展示
- 文章详情页，支持代码高亮
- 前端搜索功能
- 分类和标签系统
- 完整的响应式布局（手机/平板/电脑）
- 简约的视觉设计

## 技术选型

选择了 Astro 作为主体框架，主要考虑：
- 生成静态网页，加载速度快
- 上手难度低，项目结构清晰
- 原生支持 Markdown
- 部署简单，支持多种免费平台

## 开发心得

这个项目的初衷是让不懂编程的人也能拥有和维护自己的博客。在开发过程中，最花心思的是如何让代码结构足够清晰、注释足够详细，让新手真的能看懂、能修改。

最终采用的分层架构（配置层/组件层/页面层/内容层/样式层）起到了很好的效果。每个文件和文件夹的作用都很明确，后续维护和扩展都很方便。
